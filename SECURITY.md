# Security policy

## Reporting a vulnerability

Please report security problems **privately** through GitHub:
**Security tab → "Report a vulnerability"**. Do not open a public issue for an
unfixed vulnerability.

Useful details: the app version, steps to reproduce, and, if relevant, a
minimal ZIP that triggers it. This is a small volunteer project, so replies may
take several days.

## Scope

In scope: a crafted ZIP or report file that makes the app crash, hang, write
outside its intended files, read files it should not, or execute code.

Out of scope: findings the tool does not report (it is an inspection aid, not a
guarantee that an extension is safe), and the unsigned executable triggering a
SmartScreen warning.

## Supported versions

Only the latest release receives fixes.
